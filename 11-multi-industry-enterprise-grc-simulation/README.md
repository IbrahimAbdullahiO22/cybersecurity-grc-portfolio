# Project 11 — Multi-Industry Enterprise GRC Simulation

**Status:** In progress — portfolio working package  
**Type:** Independent, synthetic GRC training project

## Objective
Apply enterprise GRC assessment principles across financial services, cloud/SaaS, manufacturing/operational technology, and healthcare. Distinguish legal obligations, examination guidance, standards, and assurance reports; evaluate evidence sufficiency; and document accountable remediation decisions.

## Industry coverage
| Industry | Primary reference points | Assessment emphasis |
|---|---|---|
| Financial services | GLBA, FFIEC guidance | Security governance, financial-sector oversight, control evidence |
| Cloud/SaaS | SOC 2, ISO 27001, CSA CCM | Cloud shared responsibility, attestation scope, control testing |
| Manufacturing/OT | NIST SP 800-82, IEC 62443 | Safety, availability, industrial segmentation, remote access |
| Healthcare | HIPAA, HITRUST CSF | ePHI protection, access governance, security assurance |

## Included working artifacts
- `cross-industry-control-mapping.md`: High-level mapping of applicable references and assessment questions.
- `evidence-and-findings-register.csv`: Synthetic assessment tracking template; no unsupported findings asserted.
- `executive-assurance-brief.md`: Draft management reporting structure and cautious conclusions.
- `portfolio-status.md`: Publication and completion limitations.

## Assessment method
1. Determine which requirements apply to the organization and service.
2. Identify risks and controls, including operational consequences.
3. Request evidence and evaluate whether it supports a control conclusion.
4. Distinguish confirmed exceptions from missing evidence and open questions.
5. Assign remediation owners and define independent closure criteria.
6. Communicate risk, limitations, and decisions to management.

## Disclaimer
All cases and records are fictional. This project documents simulated assessments, not production platform use, client work, regulatory certification, or an issued audit opinion. The files are a working portfolio package and should be updated with the learner's actual completed lesson results before describing the entire project as completed.
