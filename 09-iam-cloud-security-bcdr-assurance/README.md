# Project 09 — Integrated Enterprise Security Assurance

**PrairieTrust Healthcare Services (PTHS) — fictional organization**  
**Simulated role:** Senior GRC & Technology Risk Analyst  
**Scope:** IAM, PAM, Azure Cloud Security, and BC/DR

This project integrates **30 synthetic observations** into a consolidated assurance assessment, five prioritized enterprise risks, three cross-domain dependencies, a 30/60/90-day remediation plan, and an executive brief.

## Files
- `Project_09_Integrated_Assurance_Report.md` — complete portfolio-ready report
- `Enterprise_Risk_Heat_Map.png` — provisional enterprise risk ratings
- `Cross_Domain_Control_Dependencies.png` — three control relationships
- `30_60_90_Day_Roadmap.png` — staged remediation and independent assurance

## Evidence interpretation
Confirmed control exceptions and recovery-test failures are distinguished from Azure Policy evaluation findings, open security recommendations, assurance limitations, and unsupported assertions. **A missing record is not automatically a failed control. A failed recovery exercise is not an actual outage.**

## Disclaimer
All data, findings, organization names, and evidence are synthetic training examples. No production audit, real breach, or actual HIPAA violation is claimed. No private performance scores are published.
